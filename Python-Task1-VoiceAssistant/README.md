# Python Task 1 - Voice Assistant

## Project Description

This project is a Python-based voice assistant that listens to spoken commands and responds using speech.

## Objective

The objective of this project is to create a simple voice assistant that can understand basic voice commands and perform useful actions.

## Technologies Used

- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- datetime
- webbrowser

## Features

- Responds to "Hello" with a greeting
- Provides the current time
- Provides the current date
- Searches the web for a requested topic
- Converts responses into speech
- Handles speech that cannot be understood
- Allows the user to exit using commands such as "bye" or "stop"
