# Python Task 4 - Basic Weather App

## Project Description

This project is a Python-based weather application that retrieves current weather information for a city using an online weather service.

## Objective

The objective of this project is to display useful real-time weather information such as temperature, humidity, weather condition, and wind speed.

## Technologies Used

- Python
- Requests
- wttr.in Weather API
- JSON

## Features

- Accepts a city name from the user
- Displays temperature in Celsius
- Displays humidity
- Displays weather condition
- Displays wind speed
- Handles invalid city names
- Handles connection and data errors

## How to Run

Install the required package:

```text
python -m pip install requests
```
